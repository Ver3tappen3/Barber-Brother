# Барбершоп «Брат» — онлайн-запись

## Запуск
1. Установить Node.js (LTS).
2. Открыть папку проекта в VS Code.
3. В терминале выполнить:

```bash
npm install
npm run dev
```

4. Открыть адрес, который покажет Vite (обычно http://localhost:5173).

## Проверка сборки
```bash
npm run build
```

## Данные
- `public/data/services.json` — услуги.
- `public/data/masters.json` — мастера.
- Записи хранятся в localStorage браузера.

## Документация
- `spec.md`
- `AGENTS.md`
- `tasks.md`
- `JOURNAL.md`
- `ACCEPTANCE.md`

## Важно
Это учебный проект без сервера. Записи хранятся только в браузере и не синхронизируются между разными устройствами или браузерами.
