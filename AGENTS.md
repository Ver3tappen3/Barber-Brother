# Инструкции для ИИ-агента

## Контекст проекта
Онлайн-запись для барбершопа «Брат». Стек: React, TypeScript, Vite. Бэкенда нет. Услуги и мастера загружаются из JSON, записи хранятся в localStorage.

## Правила разработки
1. Перед изменением прочитай `spec.md` и `tasks.md`.
2. Не добавляй функции, которых нет в требованиях, без согласования.
3. Сохраняй строгую типизацию TypeScript.
4. Не используй `any`, если можно описать тип.
5. Проверяй длительность услуги при расчёте свободного времени.
6. Учитывай пересечение интервалов, а не только совпадение времени начала.
7. Для «Любой мастер» выбирай первого свободного мастера.
8. Не меняй формат телефона: +7 и ровно 10 цифр после кода страны.
9. После изменений запускай `npm run build`.
10. Обновляй `JOURNAL.md` и `ACCEPTANCE.md` после выполненной работы.

## Критерии готовности
- Проект запускается командами `npm install` и `npm run dev`.
- `npm run build` завершается без ошибок.
- Все требования R1–R16 проверены.
